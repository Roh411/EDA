# 📊 Exploratory Data Analysis (EDA) Project

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on loan/financial datasets to understand patterns, detect anomalies, and extract meaningful business insights related to credit risk and loan defaults.

---

## 🎯 Objective
To analyze the dataset and identify key factors influencing loan approval and default risk using statistical and visual techniques.

---

## 🛠️ Tools & Technologies Used
- Python 🐍  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Jupyter Notebook / Python Script  

---

---

## 📊 Steps Performed

- Data Loading from CSV files  
- Data Cleaning (handling missing values, duplicates)  
- Exploratory Data Analysis (EDA)  
- Statistical Summary of features  
- Outlier Detection  
- Correlation Analysis  
- Visualization using graphs (bar charts, histograms, heatmaps)

---

## 📈 Key Insights

- Identified important features affecting loan risk  
- Observed correlation between financial attributes  
- Detected outliers and inconsistencies in data  
- Generated business insights for credit risk evaluation
